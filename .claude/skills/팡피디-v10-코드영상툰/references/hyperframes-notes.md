# HyperFrames 스킬에서 가져온 원칙 (heygen-com/hyperframes, skills/hyperframes)

원본: https://github.com/heygen-com/hyperframes — `skills/hyperframes/SKILL.md`, `references/types/vertical.md`, `types/character.md`, `motion.md`, `captions.md`, `runtimes.md`, `sound.md`.
CLI 는 이 환경에서 실행이 막혀 있어, 아래 원칙만 `scripts/toon/` 렌더러에 구현했다.

## 렌더 규약
- 영상 = 시간 t 의 순수 함수. 매 프레임 `renderAt(t)` 로 시크해서 캡처하므로 렌더할 때마다 똑같다.
- `Date.now()`, 시드 없는 `Math.random()`, 타이머, `requestAnimationFrame` 금지. 랜덤은 mulberry32(`rng(seed)`).
- 폰트는 `@font-face` 로 로컬 파일을 물리고 `document.fonts.ready` 뒤에 캡처를 시작한다.

## 세로(9:16) 쇼츠
- 1080×1920. 위 168px(상태바) 비움. 글자·핵심은 168~1330 띠 안. 1330 아래는 앱 UI(설명·버튼)가 덮으니 장식만.
- 0프레임이 썸네일이자 훅: 얼굴 또는 굵은 한 줄이 이미 화면에 있어야 한다. 검정 화면·로고 금지.
- 컷 1~2초, 새 비트 2~4초마다, 반전(페이오프)은 넘기기 전에.
- 음소거 시청자를 위해 말은 자막으로.

## 캐릭터 연기
- 표정 변화는 예비동작 → 눌림 → 새 얼굴 → 안착. 한 프레임에 뚝 바뀌지 않는다.
- 부위를 시차·다른 양으로 움직인다(머리가 먼저, 팔이 따라옴). 양팔·양눈·군중을 똑같이 움직이지 않는다.
- 동작은 빠르게, 의미는 천천히(리액션을 잡아 준다).
- 손그림 느낌: 외곽선을 초당 12번 t 시드로 살짝 흔든다(`feTurbulence seed = floor(t*12)`).

## 모션
- 도착은 긴 꼬리 ease-out(expo/power4), 카메라·색 변화는 inOut, 퇴장은 ease-in, 퇴장은 등장보다 40~50% 짧게.
- 스프링: 감쇠 0.4~0.6 = 장난스러움, 0.3 미만 = 만화. 위치·크기만 튀고 투명도는 튀지 않는다.
- 전환 3~5종을 원인 있게 섞는다(휘프, 플래시, 딥 컷, 펀치인). 컷만 쓰지 않는다.
- 안착한 제목은 가만히 둔다(둥둥 떠다니는 루프는 생성 티).

## 자막
- 한 번에 한 그룹만. 그룹은 첫 단어 시작 전에 열리고, 끝나면 확실히 지운다.
- 세로: 하단에서 600~700px 위, 가로 최대 900~960px, 넘치면 줄바꿈(축소 대신 자르기).
- 장면에 따라 밝기 대비: 흰 글자 + 두꺼운 검정 외곽선(paint-order stroke).

## 사운드
- 15초 넘는 이야기 영상 = 배경음악 + 화면 동작에 맞춘 효과음. 효과음은 원인이 화면에 있을 때만, 그림보다 한 프레임 늦게.
- 목소리 아래 음악 ≈ 0.14~0.22, 믹스 −16~−14 LUFS, true peak −1 dBTP 이하.
- 들어보지 못했으면 “측정만 했다”고 보고한다.
